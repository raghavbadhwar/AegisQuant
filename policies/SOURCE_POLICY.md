# Source Policy

Agents request information through typed `SourceRequest` contracts; they never execute arbitrary connector commands. Acquisition is official-first, mode-gated, allowlisted, budgeted, rate-limited, raw-captured before interpretation, normalized, versioned, and injection-scanned. Agent Reach, Scrapling, browser, and current social sources are unavailable in replay and ordinary historical mode. Source health informs routing but never proves truth.
