# Vision

AegisQuant is an evidence-first investment-research operating system for replay, historical backtesting, live research, and **simulated paper execution only**. Agents investigate and challenge; deterministic components validate provenance, calculate, size, constrain, reconcile, and govern. It will not include a live broker. Improvements compound through candidate memory and experiments, but only an independent evaluation plus explicit human decision can promote a change. See `docs/BUILD_SPEC.md` for the authoritative design.
