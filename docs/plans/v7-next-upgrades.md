# Candidate-only upgrade roadmap

All stages remain research/backtest/paper-only, candidate-only, engineering-only, and
release-gated. No stage grants broker, order, portfolio, risk, promotion, or external
network authority to historical/replay paths.

## U1: governed evidence readiness

Add approved external append-only receipt custody, accession-level XBRL revision corpus,
survivorship-safe PIT universe/actions/delistings, dated identifier history, and governed
N-PORT dissemination receipts. Exit only with reproducible coverage and holdout receipts.

## U2: empirical adaptive evaluation

Run preregistered, receipt-bound replay comparisons against a fixed baseline. Retain all
negative results and abstentions. Exit only with governed holdout evidence; never infer
investment performance from local fixtures.

## U3: bounded domain expansion

Add one mechanism/domain at a time, with units, PIT evidence, contribution reconciliation,
error bounds, and a documented kill criterion. Do not add graph breadth without a measured
benefit on governed data.

## U4: governed human workflow

Add signed identity attestations, independently retained reviewer receipts, controlled
promotion review outside v7, and audit exports. v7 remains read-only and cannot promote.

## U5: optional research simulation

Define isolated deterministic microstructure research protocols behind the existing
simulated-execution seam. Optional integrations require dependency, licence, and replay
approval before implementation.
